# SALTLINE

A playable teaser for a road game that does not exist. Drive 580 km across the invented Free State of Orrin and get a pirate radio transmitter to the last ferry before dawn.

## What is on the page

- A scroll-driven story told hour by hour through one night
- Two drivers to switch between, each with their own colours, lines and perk
- An interactive atlas of Route 9
- A 3D road game with four levels, each on a new map: Route 9, Frostline Pass, Monsoon Delta and Red Canyon Run
- Three lives per run, fuel that burns three times faster on boost, traffic, roadblocks and coins
- Six special powers: shield, coin magnet, nitro, ghost mode, double coins and a repair kit, picked up on the road or bought in the garage and fired with keys 1 to 6
- Three daily tasks with coin rewards, plus a bonus of 200 coins and a free power for claiming all three
- Four camera views for every car and truck: chase, far chase, bonnet and drone (V key or the camera button)
- Out of lives? Spend coins to respawn with one extra life; each respawn in the same run costs double (100, 200, 400...)
- A pit stop at the end of every level where you park in a marked bay to unlock the next level
- Six secrets on every level, plus four hidden in the page
- A garage shop: spend coins on nine cars and trucks and tune speed, fuel range and handling
- A working radio with three generative stations, playable in the game with the R key or the radio button
- Nine cheat codes, listed in the glovebox and usable from the pause menu during a run
- A downloadable driver's card, keyboard and touch controls, saved progress and reduced-motion support

## Run it

```bash
npm install
npm run dev
```

```bash
npm run build
```

## Built with

React, TypeScript, Vite, Three.js, Zustand and the Web Audio API.

## Original work

The world, characters, cars, story and code were written for this project. There are no image, audio or video files: all artwork is drawn in code and all sound is synthesized in the browser. Fonts are Big Shoulders Display, Overpass and Overpass Mono from Google Fonts.
