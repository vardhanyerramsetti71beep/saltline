# SALTLINE

A playable teaser for a road game that does not exist. Drive 361 miles across the invented Free State of Orrin and get a pirate radio transmitter to the last ferry before dawn.

## What is on the page

- A scroll-driven story told hour by hour through one night
- Two drivers to switch between, each with their own colours, lines and perk
- An interactive atlas with four regions
- A 3D road trip with fuel, hull, roadblocks, traffic and pickups
- A garage with three cars, seven paints and stripe options
- A working radio with three generative stations and a hidden frequency
- Six secrets, six cheat codes and a downloadable driver's card
- Keyboard and touch controls, saved progress and reduced-motion support

## Run it

```bash
npm install
npm run dev
```

```bash
npm run build
```

## Built with

React, TypeScript, Vite, Three.js, Zustand and the Web Audio API.

## Original work

The world, characters, cars, story and code were written for this project. There are no image, audio or video files: all artwork is drawn in code and all sound is synthesized in the browser. Fonts are Big Shoulders Display, Overpass and Overpass Mono from Google Fonts.
